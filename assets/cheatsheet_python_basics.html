If Statements
›if / elif / elsebranch on conditions 
x = -3
if x < 0:
    print("You entered a negative number.")
elif x > 0:
    print("You entered a positive number.")
else:
    print("You entered the number 0.")
printed
You entered a negative number.
Python checks branches top to bottom and runs the first true one. Indentation (4 spaces) defines the block.
Loops
›while looprepeat until condition is false

Always change the loop variable inside, or you get an infinite loop.

Tuples
›Immutable sequencescreate & unpack 
(1, 2, 3)              # parentheses (or just commas)
tuple("abc")           # from an iterable
a, b, c = (1, 2, 3)    # unpacking
notes
(1, 2, 3)            -> (1, 2, 3)
tuple("abc")         -> ('a', 'b', 'c')
a, b, c = (1, 2, 3)  -> unpacks to a=1, b=2, c=3
tuples are immutable: t[0] = 9  raises TypeError
Tuples can't be changed after creation, use them for fixed collections. (A mutable item inside a tuple can still change.)

Functions
›Define & calldef, return, default args 
def get_evens(n=10):          # n defaults to 10
    return [x for x in range(n) if x % 2 == 0]

get_evens()      # uses default
get_evens(6)     # positional argument
printed
[0, 2, 4, 6, 8]
[0, 2, 4]
›Positional vs keyword argsand mixing them 
def get_multiples(n=5, divisor=2):
    return [x for x in range(n) if x % divisor == 0]

get_multiples(10, 3)             # positional
get_multiples(n=10, divisor=3)   # keyword
get_multiples(10, divisor=3)     # positional THEN keyword
printed
[0, 3, 6, 9]
[0, 3, 6, 9]
[0, 3, 6, 9]
Keyword args must come after positional ones. Params with defaults must come after params without.
PEP8 & Best Practices
›Style guidelinesreadable code is shareable code
namingsnake_case for variables and functions
indentation4 spaces, never tabs (do not mix)
whitespacespaces around binary operators: x = i * 2 - 1
line lengthkeep lines under ~79 chars; break long expressions
avoid namesl, O, I as single-char names (look like 1/0)
operatorsat line breaks, keep the operator with its operand (start the new line with it)
